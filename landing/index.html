A command-line companion

Stop googling
bash syntax.

yaak is a tiny Rust CLI that translates plain English into the right shell command — using Anthropic, OpenAI, or any compatible model you choose. Describe what you want, review the command, hit enter. That's it.
Install via Homebrew
$ brew tap hanneshapke/yaak && brew install yaak
Or via Cargo
$ cargo install yaak
Set YAAK_API_KEY and go.

See it in action

Three real examples cycling below. yaak handles compression, file search, process management — anything you can describe.

01

Your brain knows what.
Let yaak know how.

Six reasons developers are replacing their Stack Overflow tab with a four-letter command.

i

Faster than searching

No more context-switching to a browser, skimming Stack Overflow, and copy-pasting flags you don't understand. Just say what you need.

ii

You stay in control

Every generated command is shown before execution. Nothing runs until you confirm. Pass -y when you trust it.

iii

Bring your own model

Works with Anthropic, OpenAI, Ollama, Groq, Together, OpenRouter, or any local server. You own the key and pick the model.

iv

Zero bloat

A single static binary. No runtime deps. Compiles in seconds, weighs under 5 MB. Rust, all the way down.

v

Knows modern tools

The LLM knows ripgrep, fd, jq, docker, kubectl, git — and picks the right one for the job.

vi

Reverse mode

Found a cryptic command? Run yaak --reverse to get a visual, token-by-token breakdown. Learn while you work.

02

Three seconds from
thought to execution.

The simplest workflow in the terminal. No configuration files, no learning curve, no magic.

Step I
Describe
Type what you want in plain English after the yaak command. No quoting needed — trailing arguments are joined automatically.
$ yaak find all rust files modified this week
Step II
Review
yaak sends your description to your configured LLM and displays the generated command. Nothing is executed yet — you have full veto power.
Command: find . -name "*.rs" -mtime -7
Execute? [Y/n]
Step III
Run
Hit enter. The command runs in your shell with your permissions. yaak exits with the same code as the command it ran.
./src/main.rs
./src/lib.rs
./tests/integration.rs
